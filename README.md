# Instahaul

**Instahaul** is an Android application developed as part of a Mobile Programming course. It is designed to make shopping from Instagram-based stores easier by bringing different online sellers and their products together in one place.

The concept is similar to delivery and marketplace apps, but focuses specifically on Instagram shops and online sellers.

## Features

* Browse stores by category:

  * Clothes
  * Jewelry
  * Accessories
  * Cosmetics
* View store information, ratings, and delivery details
* Explore products available in each store
* Simple and user-friendly mobile interface

## Technologies

* **Java**
* **Android Studio**
* **XML**

## About the Project

This project helped me strengthen my skills in Android development, mobile UI design, and building marketplace-style mobile applications.
